About CyberShield

A student project for learning cybersecurity and digital forensics.

Project Overview

CyberShield is an educational web application developed using Python and Flask. It introduces users to cybersecurity awareness and basic digital evidence handling through simple interactive tools.

Project Objectives

  • Promote safe internet practices and cybersecurity awareness.
  • Demonstrate basic password strength checking.
  • Test cybersecurity knowledge using a quiz.
  • Calculate SHA-256 hashes for selected files.
  • Generate a basic digital forensics investigation report.

Technologies Used

  • Python
  • Flask framework
  • HTML and CSS
  • JavaScript
  • SHA-256 hashing

Learning Outcome

This project provides practical experience with web development, cybersecurity awareness, file hashing, and basic report preparation. The tools are for educational use and do not replace professional malware analysis or a complete forensic investigation.
